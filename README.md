# AutoBotShelf submissions

Public suggestions and problem reports for [AutoBotShelf](https://autobotshelf.com), a shelf of tested recipes for automating everyday chores.

- **[Suggest a recipe](https://github.com/pickknow/autobotshelf-submissions/issues/new?template=suggest-a-recipe.yml)**: a chore you'd like a bot for, or an automation you've built.
- **[Report a problem](https://github.com/pickknow/autobotshelf-submissions/issues/new?template=report-a-problem.yml)**: a step that stopped working, a broken link, or a changed price.

Add a 👍 to the ideas you want too. The most-wanted ones are built first, and every recipe is tested end to end before it's published. Submissions are reviewed by a person; nothing is published automatically.

Please don't include passwords, API keys or personal data in issues. This repository is public.
